<h1 align="center">Mi Cuenta Nauta</h1>

Aplicación para conectarse al portal cautivo de ETECSA (Cuba) y gestionar cuentas de navegación Nauta.

### Características principales

| Característica | Descripción |
|----------------|-------------|
| **Gestión de cuentas** | Guardar, editar y eliminar múltiples cuentas Nauta |
| **Cuenta favorita** | Acceso rápido a la cuenta más usada |
| **Temporizador configurable** | Definir duración de sesión (horas/minutos/segundos) |
| **Bandeja del sistema** | Minimizar a bandeja, acciones rápidas, auto-inicio |
| **Temas** | Soporte para tema claro/oscuro |
| **Actualizaciones** | Detección y notificación de nuevas versiones |
| **Validación** | Validación en tiempo real de usuario/contraseña |

Requisitos
OS: Windows 10/11 (x64)
Red: Conexión a internet para portal ETECSA

Email: barnesound@gmail.com

Nota: Esta aplicación no está afiliada oficialmente con ETECSA. Úsela bajo su propia responsabilidad.
